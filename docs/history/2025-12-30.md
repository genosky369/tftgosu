2. UI 테스트를 위해 더미 데이터 생성
3. TFT 메타 지식 없이 "그럴듯해 보이는" 조합 임의 생성

## METAsrc 방식 복합 점수 티어 시스템 적용

### 문제점
- 기존 티어 기준: 단순 평균 등수 (S: ≤3.5등, A: ≤4.0등, B: ≤4.3등)
- **결과**: S티어 0개, 대부분 C티어로 분류 → 티어리스트 의미 없음

### 해결책: METAsrc 방식 복합 점수 도입

**복합 점수 공식:**
```
CompositeScore = PlacementScore(40%) + Top4Score(25%) + WinScore(20%) + ConsistencyScore(15%)
```

| 지표 | 가중치 | 계산 방식 |
|------|--------|-----------|
| 평균 등수 점수 | 40% | `(8 - avgPlacement) / 7 * 100` |
| Top4 비율 점수 | 25% | `top4Rate` (그대로 사용) |
| 1등 비율 점수 | 20% | `min(winRate * 5, 100)` |
| 안정성 점수 | 15% | `max((4 - stdDev) / 3 * 100, 0)` |

**티어 기준:**
| 티어 | 복합 점수 |
|------|-----------|
| S | ≥ 65점 |
| A | ≥ 55점 |
| B | ≥ 45점 |
| C | < 45점 |
