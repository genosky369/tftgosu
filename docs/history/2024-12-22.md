## 주요 결정사항

### 프로젝트 방향
- **핵심 기능**: 아이템 최적화 시뮬레이터 (챔피언별 최적 아이템 조합 계산)
- **타겟 사용자**: TFT 플레이어

### 기술 스택
- **프레임워크**: Next.js 14 (App Router)
- **언어**: TypeScript
- **스타일링**: Tailwind CSS
- **상태관리**: Zustand
- **선택 이유**: 가장 큰 생태계, AI 코딩 자료 풍부

### 문서화 방식
- **구조**: claude.md + docs 폴더
- **세션 기록**: 날짜별 파일 (docs/history/YYYY-MM-DD.md)
- **상세도**: 요약 + 결정사항 중심
