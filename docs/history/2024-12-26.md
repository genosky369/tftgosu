### 8. 데이터 파이프라인 문서화 및 정리

스킬 스케일링 데이터 관리 방식을 명확히 정리.

**결정사항**:
- `ability-scaling.json` 파일 삭제 (중복 데이터였음)
- Community Dragon 원본 데이터(`set16-champions.json`)를 직접 사용
- 스킬 스케일링은 `ability.variables` 배열에서 접근

**스케일링 데이터 접근법**:
```typescript
// 유나라 AD 스케일링 예시
const yunara = champions.find(c => c.name === 'Yunara');
const adVar = yunara.ability.variables.find(v => v.name === 'ADDamage');

// value[1]=1성, value[2]=2성, value[3]=3성
const adRatio1Star = adVar.value[1]; // 85 (= 85% AD)
const adRatio3Star = adVar.value[3]; // 450 (= 450% AD)
```

### 스킬 스케일링 데이터 접근

**문서**: `docs/data/DATA_PIPELINE.md`

스킬 스케일링은 별도 파일 없이 `set16-champions.json`의 `ability.variables`에서 직접 접근:

| 변수명 | 의미 |
|--------|------|
| `ADDamage` | AD 스케일링 (%) |
| `APDamage` | AP 스케일링 (%) |
| `BaseMagicDamage` | 기본 마법 피해 |
| `AttackSpeed` | 공격속도 보너스 |
| `StunDuration` | 기절 시간 |

인덱스 규칙: `value[1]=1성, value[2]=2성, value[3]=3성`
