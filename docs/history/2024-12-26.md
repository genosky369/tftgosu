### 7. Community Dragon 데이터 파싱 및 자동화 스크립트

DPS 계산기 등 향후 기능을 위해 TFT Set 16 데이터를 Community Dragon에서 파싱.

**데이터 소스**: `https://raw.communitydragon.org/latest/cdragon/tft/en_us.json` (20MB)

| 데이터 | 수량 | 포함 정보 |
|--------|------|-----------|
| 챔피언 | 100명 | HP, AD, 방어력, 마저, 공속, 치명타, 마나, 사거리, 스킬 |
| 특성 | 53개 | 이름, 설명, 단계별 효과 |
| 기본 아이템 | 10개 | 컴포넌트 아이템 |
| 조합 아이템 | 51개 | 스탯, 조합법, 효과 설명 |
| 찬란한 아이템 | 45개 | Radiant 버전 아이템 |

**자동화 스크립트**: `npm run update-tft-data`
- Community Dragon에서 최신 데이터 다운로드
- 챔피언, 특성, 아이템 자동 파싱
- 패치 시 한 번의 명령으로 데이터 갱신 가능

| 파일 | 변경 내용 |
|------|-----------|
| `src/data/set16-champions.json` | Set 16 챔피언 데이터 (125KB) |
| `src/data/set16-traits.json` | Set 16 특성 데이터 |
| `src/data/set16-items.json` | Set 16 아이템 데이터 (기본/조합/찬란한) |
| `scripts/update-tft-data.js` | 데이터 자동 갱신 스크립트 |
| `package.json` | update-tft-data 스크립트 추가 |

| `CALCULABLE_REGIONS` | 13개 | 지역 조합 생성 (다르킨만 제외) |

### 보유 챔피언 기능 상호 배제

```typescript
// 제외 중인 챔피언은 보유 선택 불가
if (excludedChampions.includes(championName)) return;

// 보유 중인 챔피언은 제외 선택 불가
if (ownedChampions.includes(championName)) return;
```
