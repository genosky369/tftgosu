## 기술 상세

### 브론즈 시뮬레이터 알고리즘
```
1. 챔피언별 브론즈 기여도 점수 계산
   - 브론즈 시너지 포함 여부
   - threshold가 낮을수록 높은 점수
   - 시너지 개수 보너스

2. 상위 35개 후보군 선택 (성능 최적화)

3. 조합 생성 (레벨 수만큼 선택)
   - 최대 50,000회 평가 제한

4. 결과 정렬 및 중복 제거
   - 상위 50개 반환
```

### 상징 중복 선택 구현
```typescript
// 상징별 개수 저장
```
