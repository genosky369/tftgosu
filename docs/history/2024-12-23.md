## 기술 상세

### 브론즈 시뮬레이터 알고리즘
```
1. 챔피언별 브론즈 기여도 점수 계산
   - 브론즈 시너지 포함 여부
   - threshold가 낮을수록 높은 점수
   - 시너지 개수 보너스

2. 상위 35개 후보군 선택 (성능 최적화)

3. 조합 생성 (레벨 수만큼 선택)
   - 최대 50,000회 평가 제한

4. 결과 정렬 및 중복 제거
   - 상위 50개 반환
```

### 상징 중복 선택 구현
```typescript
// 상징별 개수 저장
const [symbolCounts, setSymbolCounts] = useState<Record<string, number>>({});

// 계산 시 배열로 변환
// { "녹서스": 3 } → ["녹서스", "녹서스", "녹서스"]
```

## 월드룬 시뮬레이터 (신규)

### 주요 결정사항

| 항목 | 결정 내용 |
|------|-----------|
| **목표** | 지역 4개를 가장 빠르게 활성화하는 조합 찾기 |
| **알고리즘** | Greedy 알고리즘 (Set Cover 문제) |
| **지역 활성화 조건** | 지역별 상이 (타곤/다르킨:1, 공허/요들:2, 녹서스/데마시아:3 등) |
| **상징 최대 개수** | 4개 (브론즈는 7개) |
| **Lv.10** | 제거 (비현실적) |

### 필터링 기능

| 기능 | 설명 |
|------|------|
| **지역 제외** | 특정 지역을 목표에서 제외 |
| **챔피언 제외** | 개별 챔피언 제외 + 해금 챔피언 일괄 제외 |
| **최대 코스트** | 1~5코 제한 설정 |
| **해금 챔피언 제외** | 체크박스 하나로 40개 일괄 제외 |

### 해금 챔피언 (40개)
퀘스트로 해금해야 사용 가능한 챔피언들
- 1코: 그레이브즈, 바드, 뽀삐, 오리아나, 요릭, 트린다미어
- 2코: 그웬, 다리우스, 르블랑, 케넨, 코부코와 유미
- 3코: 나서스, 니달리, 다이애나, 레넥톤 등 14개
- 4코: 갈리오, 멜, 세트, 볼리베어 등 10개
- 5코: 라이즈, 브록, 사일러스, 아우렐리온 솔, 자헨
