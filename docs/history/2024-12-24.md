### 2. 게시판 페이지 버그 수정
**문제**: `use(params)` 에러 - "An unsupported type was passed to use()"

**원인**: Next.js 14에서 페이지 컴포넌트의 `params`는 일반 객체 (Promise 아님)

**수정**:
```typescript
// 이전 (잘못됨)
import { use } from "react";
export default function Page({ params }: { params: Promise<{ id: string }> }) {
  const { id } = use(params);

// 이후 (수정됨)
export default function Page({ params }: { params: { id: string } }) {
  const { id } = params;
```

### 3. Supabase 트러블슈팅
로그인 구현 시 발생한 문제들과 해결 방법을 CLAUDE.md에 문서화

| 문제 | 원인 | 해결 |
|------|------|------|
| Missing env variables | `.env.local` 없음 | 파일 생성 |
| 서버 오류 | 잘못된 API Key | `eyJ...` JWT 형식 사용 |
| 로그인 실패 | 테이블/RLS 없음 | SQL 스키마 + 정책 실행 |
| 비밀번호 불일치 | bcrypt 버전 차이 | 프로젝트 bcryptjs로 해시 생성 |

- 관리자 계정 변경 (admin → genosky)
- 로그인 화면 초기계정 안내 텍스트 제거

### 구현된 기능

#### 방문자 통계 API
| 엔드포인트 | 메서드 | 설명 |
|-----------|--------|------|
| `/api/visitors` | POST | IP + 날짜 기준 방문 기록 |
| `/api/visitors` | GET | 오늘/전체 방문자 수 조회 |

#### 동작 방식
1. 홈페이지 로드 시 `POST /api/visitors` 호출 → 방문 기록
2. 관리자 대시보드에서 `GET /api/visitors` 호출 → 통계 표시
3. 같은 IP는 하루에 1번만 카운트 (일일 유니크)
