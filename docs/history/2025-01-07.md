## 주요 결정사항

### 메타 티어리스트 라이브 노출 문제
- **문제**: 메타 티어리스트 기능이 로컬 테스트도 완료되지 않은 상태에서 라이브(tftgosu.com)에 메뉴로 노출됨
- **원인**: 이전 세션에서 Header.tsx에 메뉴 추가 후 push하면서 의도치 않게 라이브에 배포됨
- **해결**: Header.tsx에서 메타 티어리스트 메뉴 제거 (주석 처리)
- **교훈**: 미완성 기능은 네비게이션에 추가하지 않거나, 환경변수로 제어해야 함

### 데이터 수집 진행
- Riot API 키 `.env.local`에 추가
- `node scripts/collect-tft-data.js` 백그라운드 실행 시작
- 챌린저 상위 200명 매치 데이터 수집 중 (약 1.5시간 소요 예상)
