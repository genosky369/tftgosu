## MCP 학습 내용

### MCP란?
Model Context Protocol - Claude를 외부 도구/데이터베이스/API와 연결하는 표준 프로토콜

"Claude가 할 수 있는 일을 확장하는 플러그인 시스템"

### tftgosu 프로젝트에 추천하는 MCP
| MCP | 용도 | 추천도 |
|-----|------|--------|
| **GitHub** | PR 리뷰, 이슈 관리 자동화 | ⭐⭐⭐ |
| **PostgreSQL (Supabase)** | DB 직접 쿼리, 통계 조회 | ⭐⭐⭐ |
| **Sentry** | 에러 모니터링 | ⭐⭐ |
| **Brave Search** | 웹 검색 (TFT 메타 조사) | ⭐⭐ |

### 설정 방법
```bash
# GitHub MCP (user scope - 모든 프로젝트에서 사용)
claude mcp add --transport http --scope user github https://api.githubcopilot.com/mcp/

# Supabase DB
claude mcp add --transport stdio db -- npx -y @bytebase/dbhub --dsn "postgresql://..."

# MCP 목록 확인
claude mcp list

# Claude Code 내에서 MCP 상태 확인 및 인증
/mcp
```

### 설정 파일 위치
| 스코프 | 파일 | 용도 |
|--------|------|------|
| Local | `~/.claude.json` (프로젝트별) | 개인용 (API 키 등) |
| Project | `.mcp.json` (프로젝트 루트) | 팀 공유 가능 |
| User | `~/.claude.json` (전역) | 모든 프로젝트에서 사용 |
