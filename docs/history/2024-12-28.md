## 주요 결정사항

### 데이터 표시 수정
- 기존: "총 30,947게임 분석" (중복 카운트된 값)
- 변경: "16,509개 플레이어 데이터 기반" (실제 레코드 수)
- 이유: 각 조합별 매칭 횟수 합계가 아닌, 실제 DB 레코드 수를 표시

### 중복 조합 제거
- 문제: (밤의 끝자락 + 크라켄의 분노)와 (크라켄의 분노 + 밤의 끝자락)이 별도로 표시
- 해결: `[A, B].sort().join("|")`로 키 생성하여 동일 조합은 1번만 표시
