### 버그 수정
| 문제 | 원인 | 해결 |
|------|------|------|
| 완성+완성이 항상 완성+조합보다 높게 표시 | 두 케이스에 같은 플레이어가 중복 카운트됨 | Case 1에서 Case 2 해당 플레이어 제외 |

**상세 원인:**
- Case 1 (완성+조합2개): 메인 아이템 + 남은 조합으로 만든 아이템 보유자
- Case 2 (완성+완성): 메인 아이템 + 두 번째 아이템 모두 보유자
- 문제: Case 2 플레이어가 Case 1에도 포함되어 Case 1 통계가 희석됨
- 해결: `exactSecondItem` 변수로 정확한 두 번째 아이템을 추적하고, 해당 아이템 보유자는 Case 1에서 제외

### 비교 로직 전체 검증

**의문점:**
- 사용자: "완성+완성이 전반적으로 등수가 더 높은 것 같은데, 로직이 꼬인 것 아닌가?"

**검증 방법:**
- 330개 4조합 케이스 전체 분석 (scripts/analyze-comparison.js)
- 완성+완성 (666개 케이스) vs 각각활용 (1,260개 케이스) 비교

**분석 결과:**
| 유형 | 케이스 수 | 총 게임 수 | 가중 평균 등수 |
|------|-----------|------------|----------------|
| 완성+완성 | 666개 | 874,431 | 4.343등 |
| 각각활용 | 1,260개 | 3,740,159 | 4.563등 |

**차이: 0.22등 (완성+완성이 더 좋음)**

**결론: 로직 오류는 아니나, 차이 원인 분석 필요**
- 0.22등 차이가 발생하는 원인은 명확하지 않음
- 각각활용도 결국 완성 아이템이므로 "시너지" 설명은 부적절
- 개별 케이스에서는 각각활용이 이기는 경우도 존재 (예: 거인학살자+가고일 4.48등 vs 거인학살자+각각활용 4.31등)
- 추가 분석 필요 (아래 참조)

### 추가 분석: 같은 메인 아이템 기준 비교

**스크립트**: `scripts/analyze-same-main-item.js`

**결과**: 36개 메인 아이템 전부 완성+완성 승리 (100%)

| 지표 | 완성+완성 | 각각활용 |
|------|----------|---------|
| 승리 아이템 수 | 36개 (100%) | 0개 (0%) |
| 전체 평균 | 4.343등 | 4.562등 |

**발견된 문제: 비교 대상이 불공정함**

```
4개 조합 (대검+장갑+벨트+활)으로:

완성+완성: 무한의 대검(대검+장갑) + 내셔의 이빨(벨트+활)
→ 4개 조합으로 2개 아이템 완성

각각활용: 무한의 대검(대검+장갑) + 벨트로 만든 템 + 활로 만든 템
→ 벨트로 만든 템 = 벨트 + ??? (5번째 조합 필요!)
→ 활로 만든 템 = 활 + ??? (6번째 조합 필요!)
→ 최소 6개 조합이 있어야 가능
```

**결론**: 각각활용 필터는 "6개 이상 조합을 가진 플레이어"를 잡고 있어서 비교가 불공정함

### 해결 방안: 최소 조합 개수 필터 추가

**요구사항**:
- 4개 조합 아이템 선택 시, 최소 6개 조합아이템을 보유한 플레이어만 필터링
- 이렇게 해야 완성+완성과 각각활용이 동일한 조건에서 비교 가능

**구현 방법**:
1. 플레이어의 모든 완성 아이템을 조합 아이템으로 분해
2. 총 조합 아이템 개수 계산
3. 최소 6개 이상인 플레이어만 통계에 포함

**예시**:
```
플레이어 A:
- 무한의 대검 (대검+장갑) = 2개
- 내셔의 이빨 (벨트+활) = 2개
- 피바라기 (대검+망토) = 2개
→ 총 6개 조합 ✓ 포함

플레이어 B:
- 무한의 대검 (대검+장갑) = 2개
- 내셔의 이빨 (벨트+활) = 2개
→ 총 4개 조합 ✗ 제외
```

### 거인 학살자 상세 분석

**스크립트**: `scripts/analyze-giant-slayer-detail.js`

**질문**: 왜 거인 학살자만 각각활용이 더 좋은가?

**발견**: 가고일 돌갑옷이 약한 아이템

| 조합 | 평균 등수 | vs 가고일 |
|------|----------|----------|
| 가고일 돌갑옷 (완성+완성) | 4.22등 | 기준 |
| 수호자의 맹세 + 적응형 투구 | 3.60등 | 0.62등 좋음 |
| 크라운가드 + 저녁갑주 | 3.61등 | 0.61등 좋음 |
| 거인의 결의 + 피바라기 | 3.71등 | 0.51등 좋음 |

**원인**:
1. 거인 학살자 = 공격템 (캐리용)
2. 가고일 돌갑옷 = 순수 방어템 (탱커용)
3. 두 아이템의 시너지가 없음
4. 갑옷+망토를 나눠서 캐리 친화적 아이템을 만들면 더 좋음

**결론**: "완성+완성 vs 각각활용" 차이가 아니라, **특정 아이템 조합의 시너지** 문제

### ⚠️ 중요 발견: 필터링 편향 문제

**스크립트**: `scripts/analyze-filter-bias.js`

**사용자 질문:**
> "완성+완성이라고 아이템 개수가 더 많을 이유는 없잖아"
> "예: 밤의끝자락+구인수가 밤의끝자락+최후의속삭임+라바돈보다 아이템이 더 많다고?"

**분석 결과:**

| 지표 | 완성+완성 | 각각활용 |
|------|----------|---------|
| 플레이어 수 | 843명 | 7,680명 |
| 평균 아이템 | **12.64개** | **10.88개** |
| 차이 | +1.77개 | - |

**아이템 개수별 내셔의 이빨 보유 확률:**

| 아이템 개수 | 내셔 보유율 |
|------------|-----------|
| 8개 이하 | 2~5% |
| 12개 | 12.7% |
| 15개 이상 | 20~36% |

**근본 원인: 필터링 조건의 비대칭성**

```
완성+완성 필터: "무한의 대검 + 내셔의 이빨 동시 보유"
  → 특정 2개 아이템을 동시에 갖는 까다로운 조건
  → 아이템이 많을수록 조건 충족 확률 증가

각각활용 필터: "무한의 대검 + 아무 벨트템 + 아무 활템 + 내셔 미보유"
  → 넓은 범위의 아이템 조건 (충족 쉬움)
  → "내셔 미보유" 조건은 아이템 적을수록 유리
```

**결론:**
- 현재 필터는 "같은 조합을 가진 플레이어"가 아니라 "우연히 해당 아이템을 가진 플레이어"를 비교
- 완성+완성 그룹 = 아이템 많은 플레이어 (평균 12.6개)
- 각각활용 그룹 = 아이템 적은 플레이어 (평균 10.9개)
- **"완성+완성이 더 좋다"는 결론이 아니라, "필터 조건으로 인한 선택 편향"**
- 같은 아이템 개수로 비교하면 차이가 거의 없음 (0.02등)

**교훈:**
- 통계 분석 시 필터링 조건이 숨겨진 편향을 만들 수 있음
- "A vs B" 비교 시, A 조건과 B 조건이 동일한 모집단을 대상으로 하는지 확인 필요

