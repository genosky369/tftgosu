# 2025-12-29 세션 기록

## 요약
- MetaTFT 사이트 구조 분석 (기획적 관점)
- TFT 조합 분류 방식 연구 (K-means 클러스터링)
- 신규 기능 아이디어: 초반 보드 → 최종 덱 추천기
- **Riot API 활용 웹 기능 기획** (Overwolf 없이 가능한 것들)
- **메타 조합 티어리스트 상세 기획 확정**

## 주요 결정사항

### MetaTFT 분석 결과
1. **플랫폼 구성**: 웹사이트 + Overwolf 데스크톱 앱
2. **핵심 기능**: Comps, Items, Augments, Units, Tier Lists
3. **데이터 규모**: 매일 200만+ 게임 분석, 5분마다 업데이트
4. **수익 모델**: 무료 + 프리미엄 구독

### TFT 조합 분류 방식
1. **K-means 클러스터링**: 최종 보드를 벡터화하여 유사한 조합 그룹화
2. **챔피언 벡터**: 각 게임을 [챔피언1 유무, 챔피언2 유무, ...] 형태로 변환
3. **거리 계산**: 챔피언 구성이 유사하면 같은 클러스터로 분류
4. **이름 부여**: 클러스터 내 공통 특성 분석 (예: 필트오버 6+ → "6필트오버")

### 신규 기능 아이디어: 덱 추천기 (Overwolf 필요)
**사용자 요청**:
> 챌린저 랭크 게임 다수 수집 → 유저가 초반 단계에서 자신의 덱 구성과 아이템 보유 현황 그리고 증강을 입력 → 이 상황에서 갈만한 덱을 추천해줌

**핵심 발견 - Riot API 한계**:
- Riot API는 **최종 게임 상태만** 제공
- 라운드별/스테이지별 보드 상태는 제공하지 않음
- MetaTFT는 Overwolf 앱으로 실시간 데이터 캡처하여 해결
- **Overwolf 앱 = 유저가 다운로드 필요** → 웹만으로는 불가능

## Riot API 활용 웹 기능 기획

### Riot API가 제공하는 데이터 (게임 종료 시점)

```
참가자(Participant) 데이터
├── placement        : 최종 등수 (1~8)
├── level            : 최종 레벨 (6~10)
├── last_round       : 탈락 라운드 (예: 25 = 5-4)
├── gold_left        : 남은 골드
├── time_eliminated  : 탈락까지 걸린 시간 (초)
├── players_eliminated: 처치한 플레이어 수
├── augments[]       : 선택한 증강 3개
├── traits[]         : 활성 시너지 목록 + 티어
└── units[]          : 최종 보드 챔피언 + 아이템 + 성급
```

## 메타 조합 티어리스트 상세 기획 (확정)

### 확정된 설정

| 항목 | 결정 | 이유 |
|------|------|------|
| **아이템 분석 범위** | 완성 아이템 + 재료 아이템 둘 다 | 완성템은 "뭘 만들지", 재료템은 "초반에 뭘 집을지" |
| **시각화 방식** | 히스토그램 (막대그래프) | 가장 직관적 |
| **최소 표본 수** | 200게임 | 신뢰도 확보 |
| **데이터 갱신 주기** | 1일 1회 | 서버 부하 최소화 |
| **비추천 아이템** | 별도 표시 없음 | 우선순위 낮은 것만 표시 |
| **덱 이름** | 자동 생성 → 필요시 수동 수정 | 효율성 + 품질 관리 |

### 핵심 기능 1: 아이템 우선순위

```
[완성 아이템]
1. 레이지블레이드    2.9등 (-0.8등) | 82%
2. 자이언트슬레이어  3.0등 (-0.6등) | 75%
3. 최후의 속삭임     3.1등 (-0.4등) | 58%

[재료 아이템] (초반 확보 우선순위)
1. 활 (곡궁)         3.0등 (-0.5등) | 78%
2. BF 대검           3.1등 (-0.4등) | 72%
```

**로직**:
- 등수 개선 효과 (40%) + 픽률 (30%) + 표본 크기 신뢰도 (30%)
- Delta = 이 아이템 있을 때 평균 등수 - 없을 때 평균 등수

### 핵심 기능 2: 등수 편차 (변동성) 시각화

**히스토그램으로 등수 분포 표시**:
```
6필트오버 징크스 (평균 3.2등)

1등 ████████████████████ 18%
2등 ███████████████████ 17%
3등 █████████████████ 15%
4등 ██████████████ 12%
...
```

**표준편차 해석**:
- < 2.0: 안정적인 덱
- 2.0~2.5: 보통
- > 2.5: 도박성 덱 (1등 or 8등)
