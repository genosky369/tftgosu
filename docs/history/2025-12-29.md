# 2025-12-29 세션 기록

## 요약
- MetaTFT 사이트 구조 분석 (기획적 관점)
- TFT 조합 분류 방식 연구 (K-means 클러스터링)
- 신규 기능 아이디어: 초반 보드 → 최종 덱 추천기
- **Riot API 활용 웹 기능 기획** (Overwolf 없이 가능한 것들)

## 주요 결정사항

### MetaTFT 분석 결과
1. **플랫폼 구성**: 웹사이트 + Overwolf 데스크톱 앱
2. **핵심 기능**: Comps, Items, Augments, Units, Tier Lists
3. **데이터 규모**: 매일 200만+ 게임 분석, 5분마다 업데이트
4. **수익 모델**: 무료 + 프리미엄 구독

### TFT 조합 분류 방식
1. **K-means 클러스터링**: 최종 보드를 벡터화하여 유사한 조합 그룹화
2. **챔피언 벡터**: 각 게임을 [챔피언1 유무, 챔피언2 유무, ...] 형태로 변환
3. **거리 계산**: 챔피언 구성이 유사하면 같은 클러스터로 분류
4. **이름 부여**: 클러스터 내 공통 특성 분석 (예: 필트오버 6+ → "6필트오버")

### 신규 기능 아이디어: 덱 추천기 (Overwolf 필요)
**사용자 요청**:
> 챌린저 랭크 게임 다수 수집 → 유저가 초반 단계에서 자신의 덱 구성과 아이템 보유 현황 그리고 증강을 입력 → 이 상황에서 갈만한 덱을 추천해줌

**핵심 발견 - Riot API 한계**:
- Riot API는 **최종 게임 상태만** 제공
- 라운드별/스테이지별 보드 상태는 제공하지 않음
- MetaTFT는 Overwolf 앱으로 실시간 데이터 캡처하여 해결
- **Overwolf 앱 = 유저가 다운로드 필요** → 웹만으로는 불가능

## Riot API 활용 웹 기능 기획 (핵심)

### Riot API가 제공하는 데이터 (게임 종료 시점)

```
참가자(Participant) 데이터
├── placement        : 최종 등수 (1~8)
├── level            : 최종 레벨 (6~10)
├── last_round       : 탈락 라운드 (예: 25 = 5-4)
├── gold_left        : 남은 골드
├── time_eliminated  : 탈락까지 걸린 시간 (초)
├── players_eliminated: 처치한 플레이어 수
├── augments[]       : 선택한 증강 3개
├── traits[]         : 활성 시너지 목록 + 티어
└── units[]          : 최종 보드 챔피언 + 아이템 + 성급
```

### 1순위 추천: 증강 분석기

**차별화 포인트**:
- MetaTFT: Riot 정책으로 실시간 증강 통계 불가 → 전문가 수동 큐레이션
- tftgosu: **게임 종료 후 데이터만 사용** → 정책 위반 아님
- 챌린저 실제 데이터 기반 증강 티어리스트 제공 가능

**기능 상세**:
```
┌─────────────────────────────────────────────────────────────┐
│  📊 증강 티어리스트                                          │
├─────────────────────────────────────────────────────────────┤
│  1티어 증강 (2-1)                                            │
│  ├─ 필트오버 문장    평균 3.4등  픽률 8.2%  게임수 520       │
│  ├─ 사이버네틱 임플란트 평균 3.6등  픽률 6.1%               │
│  └─ ...                                                     │
│                                                             │
│  2티어 증강 (3-2) / 3티어 증강 (4-2)                         │
└─────────────────────────────────────────────────────────────┘

추가 분석:
- 증강 조합 시너지 (A증강 + B증강 = 평균 등수?)
- 특정 조합에서 좋은 증강 (6필트오버 + 이 증강 = ?)
```

### 2순위: 메타 조합 티어리스트

```
┌─────────────────────────────────────────────────────────────┐
│  📊 메타 조합 티어리스트                                     │
├─────────────────────────────────────────────────────────────┤
│  S티어                                                       │
│  ├─ 6필트오버 징크스  평균 3.2등  Top4 72%  게임수 1,240    │
│  └─ [징크스][바이][직스][세라핀][이즈리얼][자이라]          │
│                                                             │
│  A티어                                                       │
│  └─ 4아르카나 제라스  평균 3.8등  Top4 65%  게임수 890      │
└─────────────────────────────────────────────────────────────┘

구현 방식:
1. 챌린저 게임 수집 (이미 완료)
2. 최종 보드를 K-means 클러스터링
3. 각 클러스터의 평균 등수 계산
4. 티어 분류 (평균 3.5 이하 = S, 4.0 이하 = A, ...)
```

### 3순위: 챔피언 분석기

```
┌─────────────────────────────────────────────────────────────┐
│  👤 징크스 분석                                              │
├─────────────────────────────────────────────────────────────┤
│  [최적 아이템 조합] (평균 등수 기준)                         │
│  1. 레이지블레이드 + 자이언트슬 + 최후의속삭임  → 2.8등     │
│  2. 레이지블레이드 + 자이언트슬 + 무한의대검    → 3.1등     │
│                                                             │
│  [성급별 성적]                                               │
│  1성: 평균 5.2등 / 2성: 평균 3.4등 / 3성: 평균 1.8등        │
│                                                             │
│  [함께 사용되는 챔피언]                                      │
│  바이 92%, 직스 88%, 세라핀 85%                             │
└─────────────────────────────────────────────────────────────┘
```
