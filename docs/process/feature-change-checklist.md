# 기능 변경 체크리스트 프로세스

> 작성일: 2024-12-23
> 배경: 말랑이 게시판 제거 시 상단 네비게이션(Header.tsx) 수정 누락

---

## 문제 분석

### 발생한 문제
- 말랑이 게시판 제거 시 관련 파일을 **수동으로** 하나씩 찾아 수정
- `Header.tsx`의 NAV_ITEMS에 말랑이가 남아있는 것을 발견하지 못함

### 근본 원인
1. **영향 분석 부재**: 변경 전 관련 파일을 체계적으로 검색하지 않음
2. **검증 단계 부재**: 변경 후 키워드가 남아있는지 확인하지 않음
3. **체크리스트 부재**: 수정해야 할 항목을 문서화하지 않음

---

## 해결: 기능 변경 프로세스

### 1단계: 영향 분석 (BEFORE 변경)

```bash
# 관련 키워드로 전체 코드베이스 검색
grep -r "키워드" src/
grep -r "키워드" docs/

# 예시: 말랑이 제거 시
grep -r "말랑" src/
grep -r "말랑" docs/
grep -r "mallang" src/
```

**결과물**: 수정해야 할 파일 목록

### 2단계: 체크리스트 작성

| # | 파일 | 변경 내용 | 상태 |
|---|------|----------|------|
| 1 | src/components/layout/Header.tsx | NAV_ITEMS에서 말랑이 제거 | ⬜ |
| 2 | src/app/page.tsx | 말랑이 섹션 제거 | ⬜ |
| 3 | docs/planning/features.md | 기능 목록에서 제거 | ⬜ |
| ... | ... | ... | ... |

### 3단계: 변경 수행

- 체크리스트의 각 항목을 순서대로 수정
- 완료 시 ✅ 표시

### 4단계: 검증 (AFTER 변경)

```bash
# 변경 키워드가 남아있는지 확인
grep -r "키워드" src/
grep -r "키워드" docs/

# 0개 결과가 나와야 함 (또는 의도적으로 남긴 것만)
```

### 5단계: 테스트

- 개발 서버 실행 후 UI에서 직접 확인
- 관련 페이지 모두 접속해서 동작 확인

## 변경 유형별 체크리스트

### A. 기능 제거 시

```
□ 1. 영향 분석: grep -r "기능명" src/ docs/
□ 2. 코드 제거
   □ 컴포넌트 파일
   □ 페이지 파일
   □ 라우팅 설정
   □ 네비게이션 (Header, Footer, Sidebar)
   □ 홈화면 링크/카드
   □ 설정 파일 (config/)
□ 3. 문서 업데이트
   □ features.md
   □ UI_WIREFRAME.md
   □ 관련 설계 문서
   □ history 기록
□ 4. 검증: grep으로 잔여 키워드 확인
□ 5. UI 테스트
```

### B. 명칭 변경 시 (예: 월드룬 → 세계룬)

```
□ 1. 영향 분석: grep -r "이전명칭" src/ docs/
□ 2. 코드 변경
   □ 컴포넌트 텍스트
   □ 설정 파일 (config/simulators.ts 등)
   □ 페이지 제목/설명
   □ alt 텍스트, 주석
□ 3. 문서 변경
   □ 모든 .md 파일에서 일괄 변경
□ 4. 검증: grep으로 이전 명칭 잔여 확인
□ 5. UI 테스트
```

### C. UI 변경 시 (아이콘/이미지 교체)

```
□ 1. 이미지 파일 준비 (public/ 폴더)
□ 2. 영향 분석: 해당 아이콘 사용하는 모든 파일
□ 3. 코드 변경
   □ 홈화면 카드
   □ 시뮬레이터 페이지 헤더
   □ 설정 파일
□ 4. 문서 변경 (와이어프레임 등)
□ 5. UI 테스트
```
