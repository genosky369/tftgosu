# TFT 시뮬레이터 - 기능 기획

> 최종 업데이트: 2024-12-22

---

## 프로젝트 개요

| 항목 | 내용 |
|------|------|
| **목적** | TFT 플레이어를 위한 시뮬레이터 웹사이트 |
| **수익 모델** | 구글 광고 (AdSense) |
| **배포** | 도메인 구매 후 웹사이트 배포 |
| **건의/문의** | 오픈 카카오톡 링크 (추후 생성) |

---

## 사이트 구조

```
홈화면
├── 시뮬레이터 (확장 가능)
│   ├── 브론즈 시뮬레이터
│   ├── 세계룬 시뮬레이터
│   └── (추후 추가될 시뮬레이터들...)
└── 자유 게시판 (+ 댓글 기능)
```

> ⚠️ **확장성 고려**: 시뮬레이터는 게임 플레이 중 새로운 아이디어가 떠오르면 추가될 수 있음.
> UI와 코드 구조를 시뮬레이터 추가가 쉽도록 설계해야 함.

## 상세 기획

### 1. 브론즈 시뮬레이터

#### 목적
"영원한 브론즈" 증강 선택 시, 브론즈 등급 시너지를 최대한 많이 활성화하는 조합 찾기

#### 증강 효과
- **골드**: 브론즈 등급 특성당 피해 증폭 2.5%
- **프리즘**: 브론즈 등급 특성당 피해 증폭 2.5% + 내구력 2%

#### 사용자 입력
| 입력 | 설명 | 제한 |
|------|------|------|
| 타겟 레벨 | 6, 7, 8, 9, 10 중 선택 | 드롭다운 |
| 보유 상징 | 가지고 있는 상징 선택 | 최대 7개 |

#### 선택 가능한 상징 목록 (25개)
```
빌지워터, 녹서스, 다르킨, 슈리마, 난동꾼, 총잡이, 요들,
기동타격대, 원거리 사격, 전쟁기계, 아이오니아, 프렐요드,
방해꾼, 비전 마법사, 기원자, 토벌자, 엄호대, 학살자,
파수꾼, 필트오버, 공허, 그림자 군도, 데마시아, 자운, 이쉬탈
```

#### 출력
| 출력 | 설명 |
|------|------|
| 조합 목록 | 브론즈 시너지 개수별 최적 조합들 |
| 필터링 옵션 | 브론즈 개수, 덱 총 코스트(비싼 순) |

#### 필터링 시나리오
```
예시:
- 브론즈 10개 조합 중 가장 비싼 덱: [챔피언 목록], 총 코스트 32
- 브론즈 9개 조합 중 가장 비싼 덱: [챔피언 목록], 총 코스트 35
→ 유저가 둘 중 더 나은 덱 판단
```

#### 데이터 소스
- `데이터/tft_set16_bronze_synergies.json` - 브론즈 시너지 40개
- `데이터/tft_set16_champions.json` - 챔피언 100개 (시너지, 코스트 정보)
- `데이터/symnbol.txt` - 상징 목록 25개

### 2. 세계룬 시뮬레이터

#### 목적
"지역 룬" 증강 선택 시, 지역 특징 4개를 가장 빠르게(적은 기물로) 활성화하는 조합 찾기

#### 증강 효과
- 무작위 지역 특성 상징 2개 획득
- 지역 특성 4개 활성화 상태로 플레이어 대전 4회 → 강력한 보상

#### 지역 목록 (14개)
공허, 그림자군도, 녹서스, 다르킨, 데마시아, 빌지워터, 슈리마, 아이오니아, 요들, 이쉬탈, 자운, 타곤, 프렐요드, 필트오버

#### 사용자 입력
| 입력 | 설명 | 제한 |
|------|------|------|
| 타겟 레벨 | 6, 7, 8, 9, 10 중 선택 | 드롭다운 |
| 보유 지역 상징 | 가지고 있는 지역 상징 선택 | 최대 4개 |

#### 출력
| 출력 | 설명 |
|------|------|
| 조합 목록 | 지역 4개 활성화하는 최소 기물 조합들 |
| 정렬 | 필요 기물 수 적은 순, 총 코스트 높은 순 |

#### 데이터 소스
- `데이터/area.txt` - 지역 목록
- `데이터/tft_set16_champions.json` - 챔피언별 지역(traits) 정보

### 3. 관리자 시스템

#### 기능
| 기능 | 설명 |
|------|------|
| 관리자 로그인 | ID: admin, PW: 설정 필요 |
| 관리자 표시 | 글 작성 시 "관리자" 뱃지 표시 |
| 글 삭제 | 자유 게시판 글/댓글 삭제 권한 |
| **방문자 통계** | 오늘 방문자수, 총 방문자수 조회 |

#### 방문자 통계 기능
| 항목 | 설명 |
|------|------|
| 오늘 방문자수 | 당일 00:00~23:59 순 방문자 (IP 기준) |
| 총 방문자수 | 서비스 시작 이후 누적 순 방문자 |
| 표시 위치 | 관리자 대시보드 (로그인 후 메인) |

```
┌─────────────────────────────────────┐
│  📊 관리자 대시보드                  │
├─────────────────────────────────────┤
│                                     │
│   오늘 방문자        총 방문자       │
│   ┌─────────┐      ┌─────────┐     │
│   │   127   │      │  4,523  │     │
│   └─────────┘      └─────────┘     │
│                                     │
│   [글 관리]  [말랑이 글쓰기]         │
│                                     │
└─────────────────────────────────────┘
```

#### 방문자 추적 방식
- **IP 기반 중복 제거**: 같은 IP는 하루에 1회만 카운트
- **데이터 저장**: DB에 방문 기록 저장 (ip, visit_date, created_at)
- **자정 리셋**: 오늘 방문자수는 자정에 자동 리셋 (DB 쿼리로 처리)

#### 보안 고려사항
- 비밀번호 암호화 저장
- 세션/토큰 기반 인증
- 관리자 페이지 접근 제한

### 4. 자유 게시판

#### 글 작성 방식
**비로그인 방식** (닉네임 + 비밀번호)
- 글 작성 시 닉네임과 비밀번호 입력
- 수정/삭제 시 비밀번호 확인

#### 기능
| 기능 | 일반 유저 | 관리자 |
|------|----------|--------|
| 글 조회 | O | O |
| 글 작성 | O (닉네임+비번) | O |
| 글 수정 | 비밀번호 일치 시 | 비밀번호 일치 시 |
| 글 삭제 | 비밀번호 일치 시 | 모든 글 |
| 댓글 작성 | O (닉네임+비번) | O |
| 댓글 삭제 | 비밀번호 일치 시 | 모든 댓글 |

#### 글 정보
- 제목
- 내용
- 작성자 (닉네임)
- 비밀번호 (암호화 저장, 표시 안 함)
- 작성일시
- 관리자 여부 표시
- 댓글 목록

#### 댓글 정보
- 내용
- 작성자 (닉네임)
- 비밀번호 (암호화 저장)
- 작성일시
- 관리자 여부 표시

## 개발 원칙

> **중요: 바이브 코딩 특성 반영**

### 기획 변경 대응
```
⚠️ 바이브 코딩 프로젝트 특성상 기획이 수시로 변경될 수 있습니다.

개발 시 다음 원칙을 따릅니다:
1. 컴포넌트는 최대한 작고 독립적으로 만들기
2. 하드코딩 최소화, 설정값은 별도 파일로 분리
3. 기능 추가/삭제가 쉬운 모듈화 구조 유지
4. 주요 로직에는 주석으로 "왜 이렇게 했는지" 설명
5. 기획 변경 시 관련 문서도 함께 업데이트
```

### 시뮬레이터 확장성 원칙

> **핵심**: 새 시뮬레이터 추가 시 설정 파일만 수정하면 자동으로 UI에 반영

```
📦 시뮬레이터 구조
src/
├── config/
│   └── simulators.ts       # 시뮬레이터 목록 설정 (여기만 수정!)
├── components/
│   └── simulator/
│       ├── SimulatorCard.tsx    # 개별 시뮬레이터 카드 (재사용)
│       ├── SimulatorGrid.tsx    # 시뮬레이터 목록 그리드
│       └── SimulatorLayout.tsx  # 시뮬레이터 페이지 공통 레이아웃
└── app/
    └── simulator/
        ├── page.tsx             # 시뮬레이터 목록 페이지
        ├── bronze/page.tsx      # 브론즈 시뮬레이터
        ├── worldrune/page.tsx   # 세계룬 시뮬레이터
        └── [id]/page.tsx        # 동적 라우팅 (선택사항)
```

#### 시뮬레이터 설정 파일 예시 (`src/config/simulators.ts`)
```typescript
export const SIMULATORS = [
  {
    id: 'bronze',
    name: '브론즈 시뮬레이터',
    description: '영원한 브론즈 시너지 최대화',
    icon: '🥉',
    color: '#cd7f32',  // 브론즈 색상
    path: '/simulator/bronze',
    status: 'active',  // active | coming-soon | disabled
  },
  {
    id: 'worldrune',
    name: '세계룬 시뮬레이터',
    description: '지역 4개 빠른 활성화',
    icon: '🌍',
    color: '#4ecdc4',
    path: '/simulator/worldrune',
    status: 'active',
  },
  // 새 시뮬레이터 추가 시 여기에 객체만 추가!
  // {
  //   id: 'new-simulator',
  //   name: '새 시뮬레이터',
  //   ...
  // },
];
```

#### 새 시뮬레이터 추가 절차
1. `src/config/simulators.ts`에 시뮬레이터 정보 추가
2. `src/app/simulator/[이름]/page.tsx` 페이지 생성
3. 필요한 데이터 파일 `데이터/` 폴더에 추가
4. `docs/planning/features.md`에 상세 기획 추가
5. 끝! (홈화면, 네비게이션은 자동 반영)

### 문서 업데이트 규칙
- 기획 변경 → `docs/planning/features.md` 업데이트
- 기능 상세 변경 → `docs/features/[기능명].md` 업데이트
- 구현 완료 → `claude.md`의 "현재 구현 상태" 업데이트
