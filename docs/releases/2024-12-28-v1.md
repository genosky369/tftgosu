## 신규 기능

### 1. 아이템 조합 분석기
- **경로**: `/simulator/item-analysis`
- **기능**: 보유한 조합 아이템으로 최적의 완성 아이템 조합 분석
- **데이터**: 최근 3일간 챌린저 상위 200명 게임 데이터 기반

#### 선택 개수별 분석
| 선택 | 분석 내용 |
|------|----------|
| 2개 | 완성 아이템 1개 통계 |
| 3개 | 완성 아이템 + 남은 조합별 통계 |
| 4개 | 완성 + 완성 조합 통계 |

#### 표시 정보
- 평균 등수
- 상위 4등 비율
- 게임 수
- 샘플 게임 (챔피언 구성 + 시너지)

### 2. 챔피언 이미지 (100개)
- 브론즈/세계룬 시뮬레이터 결과에 챔피언 이미지 표시
- 코스트별 테두리 색상 (1코 회색 ~ 5코 황금)
- 로컬 저장으로 빠른 로딩
