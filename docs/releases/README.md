# 라이브 배포 기록

이 폴더는 **tftgosu.com** 라이브 사이트에 배포된 업데이트 내역을 기록합니다.

## 파일 네이밍 규칙

```
YYYY-MM-DD-vX.md
```

예시: `2024-12-26-v1.md`, `2024-12-26-v2.md`

## 템플릿

```markdown
# 라이브 배포 YYYY-MM-DD vX

## 배포 시간
- YYYY-MM-DD HH:MM

## 포함된 기능/수정사항
- [ ] 기능 1
- [ ] 기능 2

## 관련 커밋
- `abc1234` 커밋 메시지 1
- `def5678` 커밋 메시지 2

## 배포 후 확인사항
- [ ] 메인 페이지 정상 로드
- [ ] 시뮬레이터 정상 동작
- [ ] 게시판 정상 동작

## 비고
- (특이사항, 주의점 등)
```
