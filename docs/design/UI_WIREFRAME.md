### 컴포넌트 상세

| 컴포넌트 | 설명 |
|----------|------|
| InfoBanner | 증강 설명 배너 |
| LevelSelector | 레벨 선택 버튼 그룹 (6~10) |
| SymbolSelector | 상징 선택 UI (그리드) |
| SelectedSymbols | 선택된 상징 표시 (최대 7개) |
| ResultCard | 조합 결과 카드 |
| ChampionIcon | 챔피언 아이콘 (코스트 색상) |
| SynergyBadge | 활성 시너지 뱃지 |

### 인터랙션

1. **레벨 선택**: 클릭 시 해당 레벨로 설정
2. **상징 선택**: 클릭 시 추가/제거 (토글)
3. **조합 찾기**: 계산 실행 (로딩 표시)
4. **결과 정렬**: 드롭다운으로 정렬 기준 변경
