# 라이즈 시뮬레이터 기획서

## 개요

라이즈의 지역 시너지를 최대한 많이 활성화하는 덱 조합을 찾아주는 시뮬레이터입니다.
세계룬 시뮬레이터를 베이스로 확장하여, 라이즈 해금 조건을 충족하면서 최다 지역을 활성화하는 최적 조합을 제시합니다.

---

## 핵심 목표

| 항목 | 세계룬 시뮬레이터 | 라이즈 시뮬레이터 |
|------|------------------|------------------|
| **목표** | 4지역 빠른 활성화 | **최다 지역** 활성화 |
| **레벨** | 6~9 선택 | 9 고정 (라이즈 해금 조건) |
| **라이즈** | 미포함 | **무조건 포함** (1칸 차지) |
| **상징** | 최대 4개 | 최대 4개 |

---

## 라이즈 정보 (참고)

### 해금 조건
- **4개 지역 특성 활성화 + 레벨 9** 도달 시 상점에 등장
- 한 번 구매하면 지역 수가 줄어도 계속 사용 가능

### 지역 효과
라이즈는 활성화된 지역마다 스킬이 강화됨 (최대 13개 지역):

| 지역 | 활성화 조건 | 효과 |
|------|------------|------|
| 빌지워터 | 3명 | 폭발 (인접 적 물리 데미지 25%) |
| 데마시아 | 3명 | 처형 (12% 이하 체력) |
| 프렐요드 | 3명 | 냉기 4초 + 고정 데미지 6% |
| 아이오니아 | 3명 | 추가 분열 (50% 데미지) |
| 이쉬탈 | 3명 | 10초마다 랜덤 지역 효과 |
| 녹서스 | 3명 | 관통 (적당 60% 감소) |
| 자운 | 3명 | 독 데미지 DoT |
| 필트오버 | 2명 | 3번째 시전 +40% |
| 공허 | 2명 | 방마저 30% 관통 |
| 슈리마 | 2명 | 넉업 + 보물 드랍 |
| 요들 | 2명 | 적 데미지 12% 감소 |
| 그림자군도 | 2명 | 영혼 비례 데미지 증가 |
| 타곤 | 1명 | 치유 10% |

- 레벨 9 고정 (라이즈 해금 조건)
- 라이즈가 1칸을 차지하므로 실제 조합은 **8칸**

```
└────────────────────────────────────────────────────────────┘
```

### 결과 정렬 기준
1. **지역 수 많은 순** (내림차순)
2. **챔피언 수 적은 순** (오름차순) - 효율 우선
3. **총 코스트 높은 순** (내림차순) - 강한 챔피언 우선

### 해금 안내
- 결과 조합에 **해금 챔피언**(퀘스트로 해금해야 하는 40개)이 포함되면:
  - 챔피언 카드에 🔒 아이콘 표시
  - "해금 필요 챔피언" 목록 별도 표시
- **라이즈 해금 조건** 충족 여부 표시:
  - ✓ 4지역 이상 → 조건 충족
  - ✗ 4지역 미만 → 조건 미충족 (이 경우는 발생하지 않도록 알고리즘 설계)

## 알고리즘 설계

### 입력
```typescript
interface RyzeSimulatorInput {
  regionSymbols: string[];      // 보유 지역 상징 (0~4개)
  ownedChampions: string[];     // 보유 챔피언 (0~8명)
  excludedRegions: string[];    // 제외할 지역
  excludedChampions: string[];  // 제외할 챔피언
}
```

### 출력
```typescript
interface RyzeSimulatorResult {
  champions: Champion[];        // 덱 구성 (8명, 라이즈 제외)
  activeRegions: {              // 활성화된 지역
    name: string;
    count: number;              // 해당 지역 챔피언 수
    threshold: number;          // 활성화 임계값
  }[];
  regionCount: number;          // 활성화 지역 수
  totalCost: number;            // 총 코스트
  unlockRequired: string[];     // 해금 필요 챔피언 목록
}
```

### 계산 로직
1. **후보 챔피언 필터링**
   - 제외 챔피언 제거
   - 보유 챔피언은 결과에 무조건 포함

2. **조합 탐색** (Greedy 또는 Branch & Bound)
   - 목표: 8칸으로 최대 지역 활성화
   - 상징은 가상의 챔피언처럼 처리 (해당 지역 +1)

3. **지역 활성화 판정**
   - 각 지역별 임계값(REGION_THRESHOLDS) 충족 여부 확인
   - 상징으로 인한 보너스 카운트 포함

4. **결과 정렬**
   - 지역 수 ↓ → 챔피언 수 ↑ → 코스트 ↓

5. **해금 필요 챔피언 표시**
   - 결과 챔피언 중 UNLOCK_CHAMPIONS에 포함된 챔피언 추출
