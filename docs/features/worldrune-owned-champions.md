# 세계룬 시뮬레이터 - 보유 챔피언 기능

## 개요

사용자가 현재 보유 중인 챔피언을 입력하면, 해당 챔피언을 **무조건 포함**하여 4개 지역 활성화 조합을 계산하는 기능.

---

## 배경

현재 시스템에서는 최적의 챔피언 조합을 계산해주지만, 실제 게임 상황에서는:
- 이미 보유한 챔피언이 있음
- 해당 챔피언을 활용하면서 4개 지역을 활성화하고 싶음
- 현재는 보유 챔피언을 반영할 방법이 없음

---

## 기능 변경

### 기존 흐름

```
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│ 보유 지역 상징  │ + │ 제외할 지역     │ + │ 제외할 챔피언   │
│   입력          │   │   선택          │   │   선택          │
└─────────────────┘   └─────────────────┘   └─────────────────┘
                              ↓
                    ┌─────────────────┐
                    │   결과 출력     │
                    └─────────────────┘
```

### 변경 후 흐름

```
┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐   ┌─────────────────┐
│ 보유 지역 상징  │ + │ 제외할 지역     │ + │ 제외할 챔피언   │ + │ 보유 챔피언     │
│   입력          │   │   선택          │   │   선택          │   │   선택 (신규)   │
└─────────────────┘   └─────────────────┘   └─────────────────┘   └─────────────────┘
                                    ↓
                          ┌─────────────────┐
                          │   결과 출력     │
                          │ (보유 챔피언    │
                          │  무조건 포함)   │
                          └─────────────────┘
```

## 상세 요구사항

### 1. UI 추가

| 항목 | 설명 |
|------|------|
| 위치 | "제외할 챔피언" 아래 또는 별도 섹션 |
| 제목 | "보유 중인 챔피언" 또는 "사용할 챔피언" |
| 형태 | 챔피언 선택 UI (기존 제외 챔피언과 유사) |
| 제한 | 레벨 수 이하로 제한 (예: 9레벨이면 최대 9명) |

### 2. 계산 로직 변경

```
기존:
- 모든 챔피언 중에서 최적 조합 탐색

변경:
- 보유 챔피언은 결과에 무조건 포함
- 남은 슬롯에서 추가 챔피언 탐색
- 예: 9레벨, 보유 챔피언 3명 → 6명 추가 탐색
```

### 3. 결과 출력

- 보유 챔피언은 결과 목록에서 구분 표시 (예: 별표, 다른 색상)
- 또는 "보유 챔피언: A, B, C" + "추가 필요: D, E, F" 형태로 분리

## 예시 시나리오

### 입력

```
레벨: 9
보유 지역 상징: 공허
제외할 지역: (없음)
제외할 챔피언: (없음)
보유 챔피언: 다이애나(타곤), 레오나(타곤), 벨베스(공허)
```

### 기대 결과

```
타곤, 공허, OO, OO 지역 활성화 조합:

챔피언 조합:
- 다이애나 (보유) ← 타곤
- 레오나 (보유) ← 타곤
- 벨베스 (보유) ← 공허
- 렉사이 ← 공허 (공허 활성화)
- ... (나머지 추가 챔피언)
```

## 고려사항

### 1. 보유 챔피언으로 불가능한 경우

- 보유 챔피언의 지역이 4개 지역 활성화에 적합하지 않을 수 있음
- 이 경우 "이 조합으로는 4개 지역 활성화가 불가능합니다" 메시지 표시

### 2. 보유 챔피언이 레벨 초과

- 보유 챔피언 수가 레벨보다 많으면 경고 메시지
- 예: "9레벨인데 10명 선택함"

### 3. 제외 챔피언과 보유 챔피언 충돌

- 같은 챔피언이 "제외"와 "보유"에 동시에 있으면 안 됨
- UI에서 상호 배제 처리

### 4. 타곤 지역 처리

- **타곤은 상징이 존재하지 않음** (게임 내 타곤 상징 아이템 없음)
- 따라서 "보유 지역 상징" UI에서 타곤은 표시하지 않음 (`REGION_SYMBOLS` 사용)
- "제외할 지역" UI에서도 타곤은 표시하지 않음 (제외할 이유가 없음)
- **단, 지역 조합 계산에는 타곤이 포함됨** (`CALCULABLE_REGIONS` 사용)
- 타곤 챔피언(다이애나, 레오나, 타릭 등)은 정상적으로 조합에 포함될 수 있음
