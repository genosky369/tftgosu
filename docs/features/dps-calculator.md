# DPS 계산기 (아이템 비교 시뮬레이터)

> 특정 상황에서 **어떤 아이템이 최고 DPS인지** 비교하는 도구

## 개요

### 핵심 목적
- 공격자 관점: "이 상황에서 내 캐리에게 어떤 아이템이 가장 좋을까?"
- 방어자 관점: "상대 캐리를 막으려면 내 탱커에게 어떤 아이템이 좋을까?"

### 핵심 기능
1. **아이템 3개 조합 비교**: 모든 아이템 3개 조합의 DPS를 한눈에 비교
2. **시간대별 분석**: 구인수의 격노검 같은 스택형 아이템의 시간별 효율 확인
3. **디버프 시뮬레이션**: 파열/파쇄/불태우기/상처 상태에서의 DPS 계산

### 아이템 조합 규칙
- **3개 아이템 조합**: 한 유닛에 최대 3개 아이템 장착
- **동일 아이템 중복 가능**: 구인수의 격노검 × 3 같은 조합 허용
- **조합 수**: C(아이템 수, 3) + 중복 허용 = 수천 개 조합 자동 계산

## 사용 시나리오

### 시나리오 1: 공격자 관점
> "2성 유나라로 3성 일라오이(워모그+브엄+가시)를 때릴 때, 어떤 아이템이 제일 좋을까?"

1. 공격 유닛 선택: **유나라** (2성)
2. 방어 유닛 선택: **일라오이** (3성)
3. 방어 유닛 아이템: 워모그, 브엄, 가시갑옷
4. 디버프 상태: 파쇄 ON (다른 유닛이 걸어줌)
5. **[계산]** → 모든 아이템별 DPS 비교표 출력

### 시나리오 2: 방어자 관점
> "상대 2성 킨드레드(무한+최후)를 내 2성 브라움이 얼마나 버틸 수 있을까?"

1. 방어 유닛 선택: **브라움** (2성)
2. 공격 유닛 선택: **킨드레드** (2성)
3. 공격 유닛 아이템: 무한의 대검, 최후의 속삭임
4. 디버프 상태: 없음
5. **[계산]** → 방어 아이템별 생존 시간 비교표 출력

## 입력 구성

### Step 1: 유닛 선택

| 항목 | 공격 유닛 | 방어 유닛 |
|------|----------|----------|
| 챔피언 | 드롭다운 | 드롭다운 |
| 성급 | 1/2/3성 | 1/2/3성 |

### Step 2: 고정 아이템 설정

**공격자 관점 모드**:
- 공격 유닛 아이템: **비워둠** (비교 대상)
- 방어 유닛 아이템: 0~3개 선택

**방어자 관점 모드**:
- 공격 유닛 아이템: 0~3개 선택
- 방어 유닛 아이템: **비워둠** (비교 대상)

### Step 3: 디버프 상태

방어 유닛에 적용된 디버프 (다른 아군이 걸어준다고 가정):

| 디버프 | 효과 | 적용 예시 |
|--------|------|----------|
| **파쇄** | 방어력 감소 | 자르반, 레오나 |
| **파열** | 마법저항 감소 | 럭스, 나서스 |
| **불태우기** | 지속 피해 + 힐감소 | 모렐로노미콘 |
| **상처** | 회복량 감소 | 거인 학살자 |

```
┌─────────────────────────────────────┐
│  디버프 설정                         │
├─────────────────────────────────────┤
│  □ 파쇄 (방어력 -30%)               │
│  □ 파열 (마법저항 -30%)             │
│  □ 불태우기 (초당 2% 최대체력)       │
│  □ 상처 (회복량 -50%)               │
└─────────────────────────────────────┘
```

### 1. 아이템 3개 조합별 DPS 비교표

> **참고**: 동일 아이템 중복 장착 가능 (예: 구인수의 격노검 × 3)

- 5초 기준: 죽음의 검 + 죽음의 검 + 무한의 대검 조합이 최고

- → "전투가 길어지면 구인수 스택형 조합이 좋다"

## 계산 로직

### 1. 기본 스탯 계산

#### 성급 배율
| 성급 | HP/AD 배율 |
|------|-----------|
| 1성 | ×1.0 |
| 2성 | ×1.8 |
| 3성 | ×3.24 |

#### 최종 스탯
```typescript
finalHP = baseHP × starMultiplier + itemBonusHP
finalAD = baseAD × starMultiplier + itemBonusAD
finalAP = 100 + itemBonusAP  // 기본 AP 100
finalAS = baseAS × (1 + itemBonusAS)
finalArmor = baseArmor + itemBonusArmor
finalMR = baseMR + itemBonusMR
```

### 2. 디버프 적용

```typescript
// 파쇄 (Sunder) - 방어력 30% 감소
if (spiked) effectiveArmor = finalArmor × 0.7

// 파열 (Shred) - 마법저항 30% 감소
if (shredded) effectiveMR = finalMR × 0.7

// 불태우기 (Burn) - 초당 최대체력 2% 피해 + 힐감 33%
if (burned) burnDPS = maxHP × 0.02

// 상처 (Wound) - 회복량 50% 감소
if (wounded) healingReduction = 0.5
```

### 3. 데미지 계산

#### 물리 데미지
```typescript
// 방어력 공식
damageReduction = armor / (100 + armor)
physicalDamage = rawDamage × (1 - damageReduction)

// 예시: 방어력 60
// 60 / 160 = 37.5% 감소
```

#### 마법 데미지
```typescript
// 마법저항 공식 (동일)
magicDamage = rawDamage × (100 / (100 + magicResist))
```

#### 치명타 (기댓값)
```typescript
// 확률 기반이 아닌 평균값 사용
expectedDamage = baseDamage × (1 + critChance × (critMultiplier - 1))

// 예시: 치확 25%, 치피 140%
// 100 × (1 + 0.25 × 0.4) = 110 평균 데미지
```

### 4. 마나 시스템

| 역할군 | 공격당 마나 | 초당 재생 |
|--------|------------|----------|
| Tank | 5 | 0 |
| Fighter | 10 | 0 |
| Assassin | 10 | 0 |
| Marksman | 10 | 0 |
| Mage | 7 | 2 |

```typescript
// 스킬 발동
if (currentMana >= maxMana) {
  castSkill()
  currentMana = 0
}
```

### 5. 스킬 데미지

```typescript
// 스킬 변수에서 스케일링 추출
const adRatio = getVariable('ADDamage', starLevel) / 100
const apRatio = getVariable('APDamage', starLevel) / 100

// 스킬 데미지 계산
skillDamage = (finalAD × adRatio) + (finalAP × apRatio)
```

### 6. 특수 아이템 처리

#### 구인수의 격노검 (스택형)
```typescript
// 공격마다 공속 +5%, 최대 10스택
guinsooStacks = Math.min(attackCount, 10)
bonusAS = 0.05 × guinsooStacks
```

#### 거인 학살자 (% 체력 피해)
```typescript
// 기본 공격 시 현재 체력 2% 추가 피해
bonusDamage = defenderCurrentHP × 0.02
```

#### 최후의 속삭임 (방관)
```typescript
// 방어력 30% 무시
effectiveArmor = targetArmor × 0.7
```

| 데이터 | 파일 | 용도 |
|--------|------|------|

- **데이터 소스**: Riot Data Dragon 공식 API

- **적용 대상**: 아이템명, 챔피언명
- **매핑 방식**: `apiName` → 한글 이름 조회

#### 시나리오 B: 방어력 적용

**설정**:

- 방어자: 더미 유닛 (HP=1000, 방어력=100)

- 킬타임: 1000 / 50 = 20초

#### 시나리오 C: 실제 챔피언 테스트

**설정**:
- 공격자: 유나라 1성 (AD=60, AS=0.8)
- 방어자: 일라오이 1성 (HP=1000, 방어력=50)
- 아이템: 없음
- 스킬: 제외

**손계산**:
```
유나라 AD = 60
일라오이 방어력 = 50
피해 감소 = 50 / 150 = 33.3%
실제 피해 = 60 × 0.667 = 40
공격 주기 = 1 / 0.8 = 1.25초
초당 DPS = 40 / 1.25 = 32
킬타임 = 1000 / 32 = 31.25초
```

**기대 결과**: 킬타임 약 31초 (±2초 허용)

---

#### 시나리오 D: 스킬 포함 테스트

**설정**:
- 공격자: 유나라 2성 (AD=108, AS=0.8, 마나=50, 초기마나=0)
- 방어자: 더미 유닛 (HP=2000, 방어력=50)
- 역할군: Marksman (공격당 10마나)

**손계산**:
```
기본 공격 피해 = 108 × (100/150) = 72
스킬 발동까지 = 50 / 10 = 5회 공격
5회 공격 시간 = 5 × 1.25초 = 6.25초
스킬 피해 (130% AD) = 108 × 1.3 × 0.667 = 93.6

6.25초까지:
- 기본 공격 피해: 72 × 5 = 360
- 스킬 피해: 93.6
- 총 피해: 453.6
```
