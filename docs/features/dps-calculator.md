# DPS 계산기 (아이템 비교 시뮬레이터)

> **⚠️ 폐기됨 (2024-12-27)**

## 폐기 사유

구인수의 격노검, 거인학살자 등 특수 아이템의 시간 기반 시뮬레이션 구현 시 복잡도가 과도하게 증가하여 폐기 결정.

### 주요 문제점

1. **성능 리스크**: 정적 계산 → 시간 기반 시뮬레이션 전환 시 계산량 20배 증가
2. **아키텍처 복잡도**: 특수 아이템 조합별 분기 처리 폭발
3. **정확도 불확실**: 실제 게임과의 검증 어려움 (틱 레이트, 스택 타이밍 등)
4. **유지보수 부담**: 향후 아이템 추가 시 복잡도 기하급수적 증가

### 구현 시도 내역

- MVP 구현 완료 (기본 DPS 계산, 디버프, 공격자/방어자 관점)
- 구인수/거인학살자 시뮬레이션 구현 시도
- 리스크 분석 후 폐기 결정

## 원본 기획 (참고용)

### 핵심 목적
- 공격자 관점: "이 상황에서 내 캐리에게 어떤 아이템이 가장 좋을까?"
- 방어자 관점: "상대 캐리를 막으려면 내 탱커에게 어떤 아이템이 좋을까?"

### 핵심 기능
1. 아이템 3개 조합 비교
2. 시간대별 분석 (구인수 스택)
3. 디버프 시뮬레이션
