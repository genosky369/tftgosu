## 1. 개요

### 1.1 목적
- **자유 게시판**: 사용자들이 자유롭게 소통하는 공간

### 1.2 핵심 요구사항
| 요구사항 | 설명 |
|----------|------|
| 비로그인 글쓰기 | 닉네임 + 비밀번호 방식 |
| 댓글 기능 | 글에 대한 댓글 (대댓글 X) |
| 관리자 권한 | 모든 글/댓글 삭제 가능 |

## 2. 기술 스택 결정

### 2.1 옵션 비교

| 항목 | Supabase | Firebase |
|------|----------|----------|
| 무료 티어 | 500MB DB, 1GB Storage | 1GB DB, 5GB Storage |
| 실시간 | ✅ 지원 | ✅ 지원 |
| SQL 쿼리 | ✅ PostgreSQL | ❌ NoSQL |
| 한국어 문서 | 적음 | 많음 |
| Next.js 연동 | 쉬움 | 쉬움 |
| 학습 곡선 | 낮음 | 낮음 |

### 2.2 선택: Supabase

| 항목 | 선택 |
|------|------|
| **데이터베이스** | Supabase (PostgreSQL) |
| **인증** | JWT (자체 구현) |

**선택 이유:**
- SQL 쿼리 지원 (복잡한 조회 용이)
- 무료 티어 충분 (500MB DB)
- 이미지 업로드 없음 → Storage/Bandwidth 부담 없음

## 3. 데이터베이스 스키마

### 3.1 posts (게시글)

```sql
CREATE TABLE posts (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  title         VARCHAR(100) NOT NULL,
  content       TEXT NOT NULL,
  author        VARCHAR(30) NOT NULL,   -- 닉네임
  password_hash VARCHAR(255) NOT NULL,  -- bcrypt 해시
  is_admin      BOOLEAN DEFAULT FALSE,  -- 관리자 글 여부
  view_count    INTEGER DEFAULT 0,      -- 조회수
  created_at    TIMESTAMP DEFAULT NOW(),
  updated_at    TIMESTAMP DEFAULT NOW()
);
```

### 3.2 comments (댓글)

```sql
CREATE TABLE comments (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  post_id       UUID REFERENCES posts(id) ON DELETE CASCADE,
  content       TEXT NOT NULL,
  author        VARCHAR(30) NOT NULL,   -- 닉네임
  password_hash VARCHAR(255),           -- bcrypt 해시
  is_admin      BOOLEAN DEFAULT FALSE,  -- 관리자 댓글 여부
  created_at    TIMESTAMP DEFAULT NOW()
);
```

### 3.3 visitors (방문자 통계)

```sql
CREATE TABLE visitors (
  id         UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  ip_address VARCHAR(45) NOT NULL,      -- IPv6 지원
  visit_date DATE NOT NULL,             -- 방문 날짜
  created_at TIMESTAMP DEFAULT NOW(),

  UNIQUE(ip_address, visit_date)        -- 하루 1회만 카운트
);
```

### 3.4 admins (관리자)

```sql
CREATE TABLE admins (
  id            UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  username      VARCHAR(30) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,  -- bcrypt 해시
  created_at    TIMESTAMP DEFAULT NOW()
);
```

## 4. API 설계

### 4.1 게시글 API

| Method | Endpoint | 설명 | 인증 |
|--------|----------|------|------|
| GET | `/api/posts` | 글 목록 조회 | - |
| GET | `/api/posts/:id` | 글 상세 조회 | - |
| POST | `/api/posts` | 글 작성 | 닉네임+비번 |
| PUT | `/api/posts/:id` | 글 수정 | 비번 확인 |
| DELETE | `/api/posts/:id` | 글 삭제 | 비번 or 관리자 |

### 4.2 댓글 API

| Method | Endpoint | 설명 | 인증 |
|--------|----------|------|------|
| GET | `/api/posts/:id/comments` | 댓글 목록 | - |
| POST | `/api/posts/:id/comments` | 댓글 작성 | 닉네임+비번 |
| DELETE | `/api/comments/:id` | 댓글 삭제 | 비번 or 관리자 |

### 4.3 관리자 API

| Method | Endpoint | 설명 | 인증 |
|--------|----------|------|------|
| POST | `/api/admin/login` | 로그인 | ID+PW |
| POST | `/api/admin/logout` | 로그아웃 | JWT |
| GET | `/api/admin/stats` | 방문자 통계 | JWT |
| DELETE | `/api/admin/posts/:id` | 글 삭제 | JWT |
| DELETE | `/api/admin/comments/:id` | 댓글 삭제 | JWT |

## 7. 보안 고려사항

### 7.1 입력값 검증

| 필드 | 제한 |
|------|------|
| 닉네임 | 2~10자 |
| 비밀번호 | 4~20자 |
| 글 제목 | 2~100자 |
| 글 내용 | 1~1000자 |
| 댓글 내용 | 1~500자 |

### 7.2 비밀번호 처리
- bcrypt로 해싱 (salt rounds: 10)
- 평문 비밀번호 저장 금지
- 최소 4자 이상 요구

### 7.3 관리자 인증
- JWT 토큰 사용 (httpOnly 쿠키)
- 토큰 만료: 24시간
- 민감한 API에 미들웨어로 인증 검사

### 7.4 XSS 방지
- 사용자 입력 HTML 이스케이프
- Content-Security-Policy 헤더 설정

### 7.5 Rate Limiting
- 글 작성: IP당 1분에 3회
- 댓글 작성: IP당 1분에 10회
- 로그인 시도: IP당 5분에 5회
