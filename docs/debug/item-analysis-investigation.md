# 아이템 분석기 조사 및 개선 계획

## 문제 현상 (2024-12-27)

- 대부분의 아이템 평균 등수가 4.5등 전후로 표시됨
- 챌린저 데이터라면 더 낮아야 하지 않나?

## 조사 결론

**정상 동작 확인됨:**
- 8명 게임의 자연 평균 = 4.5등
- 무한의 대검 보유자 평균: 4.32등 (전체 평균보다 나음)
- 챌린저와 매칭되는 상대도 챌린저 수준이므로 전체 데이터 사용 OK

---

## 원인 분석

### 핵심 원인: 전체 플레이어 저장

```
현재 데이터 구조:
├── 664 게임 (tft_matches)
└── 5,312명 플레이어 (tft_players) ← 게임당 8명 전부 저장!
```

**문제점:**
- 챌린저 50명의 게임을 수집했지만, 그 게임의 **모든 8명**을 저장
- 8명 게임에서 1~8등의 평균은 자연스럽게 **4.5등**
- 챌린저가 아닌 상대방 7명도 포함되어 통계가 희석됨

### 데이터 흐름

```
1. 챌린저 50명 puuid 획득
2. 각 챌린저의 최근 20게임 매치ID 획득
3. 매치 상세 조회 → 8명 전부 저장 ← 문제!
4. API에서 모든 플레이어 대상으로 통계 계산 ← 문제!
```

## 검증 테스트 계획

### 테스트 1: 전체 데이터 평균 등수 확인

**목적:** 전체 데이터의 평균 등수가 4.5인지 확인

**방법:**
```sql
SELECT AVG(placement) FROM tft_players;
```

**예상 결과:** 약 4.5 (정상적인 8명 게임 평균)

2. 해당 puuid로 필터링하여 평균 계산

**예상 결과:** 챌린저는 평균 4등 이하여야 함

3. API 결과와 비교

## 통계 편향 문제 및 해결 (2024-12-27)

### 문제 현상

모든 아이템의 평균 등수가 4.5 미만으로 표시됨 (예: 4.15 ~ 4.36등)

### 원인 분석

**핵심**: 높은 등수 플레이어가 더 많은 아이템을 보유

```
1등 플레이어: 9개 아이템 → 9개 통계에 각각 등장
8등 플레이어: 3개 아이템 → 3개 통계에만 등장
```

**수학적 계산:**
```
아이템 인스턴스: 9+8+7+6+5+4+4+3 = 46개
1등 비율: 9/46 = 19.5%
8등 비율: 3/46 = 6.5%

가중 평균: (1×9 + 2×8 + ... + 8×3) / 46 = 3.72등
```

→ 아이템 개수 편향으로 **모든 아이템**이 4.5 미만으로 표시됨

### 해결: 가중치 적용

```typescript
// 아이템 개수에 반비례하는 가중치
const itemCount = countCompletedItems(player.units);
const weight = 1 / itemCount;

// 가중 평균 계산
const totalWeight = matchingGames.reduce((sum, g) => sum + g.weight, 0);
const weightedSum = matchingGames.reduce((sum, g) => sum + g.player.placement * g.weight, 0);
avgPlacement = weightedSum / totalWeight;
```

### 수정 결과

| 아이템 | 수정 전 | 수정 후 |
|--------|---------|---------|
| 밤의 끝자락 | ~4.1등 | 4.27등 |
| 거인 학살자 | ~4.2등 | 4.40등 |
| 죽음의 검 | ~4.2등 | 4.51등 |
| 구인수의 격노검 | ~4.3등 | 4.69등 |
| 대천사의 지팡이 | ~4.3등 | 4.59등 |

→ 이제 좋은 아이템은 4.5 미만, 나쁜 아이템은 4.5 이상으로 정상 분포
